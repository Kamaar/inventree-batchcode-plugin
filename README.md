# BatchCodePlugin v1.0

## Descrizione
Genera codici batch progressivi per gli StockItem in InvenTree.  
Versione base: codice numerico progressivo generato automaticamente alla creazione dell'item.

## Funzionalità
- Generazione automatica di codici batch numerici progressivi.
- Salvataggio del codice nel campo configurabile dello StockItem.

## Installazione
1. Copiare la cartella `batchcode_plugin` in `plugins/` di InvenTree.
2. Riavviare InvenTree.
3. Attivare il plugin dalle impostazioni.

## Configurazione
- Campo target: `batch` (default)
